# OCR Passport Postprocessing

Программа постобработки результатов OCR паспортов. Проверяет распознанные поля, сопоставляет данные VIZ и MRZ, применяет строгие правила и оценивает риск ошибки с помощью `HistGradientBoostingClassifier`.

Основной приоритет - не принимать документы с ошибками.

## Запуск

Все команды выполняются из корневой папки проекта.

### 1. Создать виртуальное окружение

```bash
python -m venv .venv
```

### 2. Активировать окружение (Windows)

```bash
.venv\Scripts\activate
```

### 3. Установить зависимости

```bash
python -m pip install -r requirements.txt
```

### 4. Запустить обработку

**Тестовые данные:**

```bash
python postprocess.py data/test_predictions.jsonl answers.jsonl
```

**Обучающие данные:**

```bash
python postprocess.py data/train_predictions.jsonl answers.jsonl
```

Результат сохраняется в `answers.jsonl`.

При запуске программа автоматически загружает обучающие данные и справочник кодов подразделений. Дополнительные параметры командной строки не требуются.

## Оценка результата

Для сравнения полученного результата с правильными ответами запустите:

```bash
python evaluate.py answers.jsonl data/train_labels.jsonl
```

Команда выше подходит для результатов, полученных на обучающих данных. Она проверяет совпадение десяти полей, но не проверяет действительность паспорта.

**Важно:** запуск на `train_predictions.jsonl` не является независимой оценкой качества, поскольку эти документы участвуют в обучении модели.
